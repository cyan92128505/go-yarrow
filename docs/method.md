# 蓍草占卜法（大衍之數）技術規格整理

## 一、演算法流程

### 初始設定
```
總數：50支蓍草
太極：1支（不參與運算）
運算用：49支
```

### 單爻求解（三變十八營）

#### 第一變（四營）
1. **分二**：49支隨機分成兩堆（象徵陰陽兩儀）
2. **掛一**：從任一堆取1支夾於指間（象徵天地人三才）
3. **揲四**：兩堆分別除以4，取餘數（1-4，整除時取4）
4. **歸奇**：餘數夾於指間（象徵閏月）

**第一變結果**：取出 5 或 9 支（1掛 + 左餘 + 右餘）
**剩餘**：40 或 44 支

#### 第二變、第三變
重複「分二、掛一、揲四、歸奇」流程
- 第二變取出：4 或 8 支
- 第三變取出：4 或 8 支

#### 最終剩餘數與爻值對應
```
剩餘策數 ÷ 4 = 爻值
24 ÷ 4 = 6  → 老陰（變爻）記為 ─ ─ ○
28 ÷ 4 = 7  → 少陽（不變）記為 ───
32 ÷ 4 = 8  → 少陰（不變）記為 ─ ─
36 ÷ 4 = 9  → 老陽（變爻）記為 ─── ○
```

### 成卦
重複六次「三變」，由下而上記錄，總計十八變成卦。

## 二、解卦規則（朱熹法）

### 變爻定義
**只有 6（老陰）和 9（老陽）為變爻**，7（少陽）和 8（少陰）不變。
